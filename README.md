# CDF 2026 - Projet EIF

Dépôt officiel pour la participation à la Coupe de France de Robotique 2026.

## Documents et Suivi

Le suivi des achats (Excel/Google Sheets) et les documents administratifs sont sur le Google Drive du projet : [Insérer le lien ici]

## Structure du dépôt

- **documents/** : Documents généraux du projet (spécifications, règlement, etc.)
- **robot_principal/** : Fichiers du robot principal
  - **electronique/** : Cartes électroniques (haut niveau, base mobile, actionneurs)
  - **mecanique/** : Conception mécanique (assemblage complet et sous-ensembles)
  - **code/** : Code embarqué (STM32) et code haut niveau (Raspberry Pi)
- **balises/** : Système de balises (électronique, code, mécanique)
- **pami_ninja/** : PAMI Ninja (électronique, mécanique, code)
- **pami_statique/** : PAMI Statique pour fin de match (électronique, mécanique, code)
